# exact_ntt — 精确卷积的多模 NTT 重建

用固定的三个 NTT 素数做数论变换（NTT），按系数界选择最少模数，再用中国
剩余定理（CRT）把模余数**精确**重建为对称区间内的整数，实现整数多项式
乘法（精确卷积）。纯 Python 标准库实现，核心蝶形迭代手写，不调用任何
第三方 FFT/NTT 实现。

## 环境与依赖

- Python **3.14.7**（仅使用标准库；3.8+ 风格的代码在相近版本亦可运行，
  但验收环境为 3.14.7）
- 无需安装任何第三方依赖，无需网络、账号、密钥、数据库或 Docker。

```bash
python -m unittest discover -s tests -v   # 运行全部测试（37 个）
python demo.py                            # 固定输入演示，毫秒级完成
```

## 接口

```python
from exact_ntt import convolve_exact, integer_convolution_info

result = convolve_exact(a, b)
result.coefficients      # list[int]，长度 len(a)+len(b)-1，精确整数
result.bound             # 证明界 B = min(n,m) * max|a_i| * max|b_j|
result.moduli            # 实际使用的 NTT 素数元组（1~3 个，固定顺序）
result.transform_length  # 补零后的 2 幂变换长度
result.modulus_product   # 所用模数乘积 M，恒有 M > 2 * bound
```

`integer_convolution_info(length_a, length_b, max_abs_a, max_abs_b)` 是
纯规划函数，不做变换，返回给定形状/界下会选用哪些模数（键：`bound`、
`moduli`、`modulus_count`、`modulus_product`、`twice_bound`、
`transform_length`、`output_length`）。

错误类型（均继承 `ExactConvolutionError`，后者继承 `ValueError`）：

| 异常 | 触发条件 |
|---|---|
| `CoefficientError` | 系数不是 `int`；是 `bool`（明确拒绝）；是 `float`（NaN/无穷带专属消息，其他浮点拒绝截断）；`|x| > 10^6` |
| `LengthError_` | 操作数为空、长度 > 256、不是 list/tuple（如生成器、字符串） |
| `ExactRecoveryError` | 三素数乘积仍 `<= 2B`，数学上可证无法精确重建（与“搜索预算耗尽”无关——本模块不存在预算型失败） |

错误消息都带定位（如 `a[7]: ...`），非法输入绝不静默纠正或取模冒充精确。
操作无状态：先完整校验两个输入再计算；不修改调用方列表（内部使用防御性
拷贝），失败时不产生任何部分结果。

## 输入上限（接口边界）

- 每个操作数长度 `1 <= n <= 256`；
- 每个系数为 `int` 且 `|x| <= 1_000_000`；
- 卷积输出系数的证明界 `B = min(n,m) * Amax * Bmax <= 256 * 10^12 = 2.56e14`。

## 固定参数

| 素数 p | p − 1 中的 2 幂 | 支持的最大变换长度 |
|---|---|---|
| 998244353 | 2^23 | 2^23 |
| 1004535809 | 2^21 | 2^21 |
| 469762049 | 2^26 | 2^26 |

原根均为 3。本契约最大输出长度 511、变换长度 512，远小于各素数上限。

## 算法与设计取舍

1. **补零到 2 幂**：长度取 `next_pow2(n+m-1)`，线性卷积不发生循环卷绕。
2. **手写迭代蝶形**：Cooley–Tukey DIT，先做位反转置换，再逐级蝶形；
   逆变换使用逆根并在末尾乘 `N^{-1} mod p`（逆长度）。
3. **最少模数选择**：按固定顺序逐枚累乘素数，第一个满足 `M > 2B` 的
   前缀即被选中。
   - `B <= 499,122,176`：1 个模数（998244353）；
   - 之后到 `B <= P1*P2/2 ≈ 5.01e17`：2 个模数（公开契约全部落在此档
     及以下，最坏 2.56e14 用两模）；
   - 再往上到 `M/2 ≈ 2.35e26`：3 个模数。
   严格不等号 `M > 2B` 保证对称区间 `[-B, B]` 内 `2B+1` 个整数互不
   别名（边界整数本身也可表示）。
4. **CRT 对称重建**：Garner 增量合并（`pow(M, -1, p)`），得到
   `[0, M)` 的规范代表后，`t > M//2` 则减去 `M` 映射到
   `[-M//2, M//2]`；再断言 `|t| <= B`。
5. **先证界后取模**：负整数只在界已被证明可覆盖之后，才在 NTT 内部
   规范到 `0..p-1`；超界输入在校验阶段即被拒绝。
6. **性能取向**：小 n（≤512）下朴素 Python 蝶形已足够（demo 毫秒级、
   全测试约 0.03 秒），因此未做递归分治、预计算旋转因子表或 numpy
   向量化；旋转因子每级现场 `pow`。

## 误差口径

输出全部是 Python 任意精度**整数**，卷积结果与朴素整数卷积逐系数相等，
不存在浮点、不存在四舍五入、不存在容差。模块不产出任何浮点数值；传入
`float`（含 NaN/Infinity）一律按非法输入拒绝，故“用宽容差掩盖边界
错误”在本模块不适用。

## 测试说明

- `tests/reference.py`：**独立**朴素整数卷积参考（O(nm) 大整数算术），
  不导入被测核心；测试期望值全部来自它。
- `tests/test_ntt.py`：NTT 与独立模朴素卷积逐值比对；正逆变换往返仅作
  补充检查。
- `tests/test_crt.py`：单/两/三模切换点、对称区间边界值、随机整数、
  可证无解分支。
- `tests/test_validation.py`：bool/NaN/Infinity/浮点/非数值拒绝、越界
  系数与长度、防御性拷贝。
- `tests/test_convolution.py`：端到端对照独立参考，覆盖全负、全零、
  长尾零、单模↔多模切换、256×256 满幅输入、确定性与不可变性。

## 已知限制

- 只实现本题契约的数学子集：仅支持三个固定素数与原根 3、2 幂变换
  长度、长度 ≤256、系数 `|x| <= 10^6`；不宣称与任何外部 NTT/格密码
  行业标准的参数集或序列化格式兼容。
- 在公开输入契约内最坏只需两个模数，第三模数路径无法通过公共入口
  触发（由 `tests/test_crt.py` 与 `tests/test_convolution.py` 直接对
  NTT/CRT 原语验证）。
- 未实现批量/流式 API；每次调用独立完成，无缓存。
- Python 大整数与解释器蝶形面向“小而精确”的题目规模，非极限吞吐
  实现。
