# 精确整数卷积：多模 NTT + CRT 重建

离线、零依赖、可导入的整数多项式乘法库。系数用 Python 大整数与模算术
处理，**全程不使用浮点**，因此结果是数学上的精确值，不存在舍入误差，
也不需要任何误差容差。

- **Python 版本**：Python 3.14.7（Linux 原生实测；任何带大整数的 Python 3
  均可运行，仅用标准库）。
- **依赖**：无第三方依赖，安装 Python 后无需 `pip install` 任何东西。
- **离线**：核心、测试、演示均不访问网络，不需要账号、密钥、数据库、
  中间件、云 API 或 Docker。演示数据由仓库内固定种子的确定性代码生成。

## 快速开始

```bash
python -m unittest discover -s tests -v   # 运行全部必要测试
python demo.py                            # 约 0.1 秒内完成的真实计算演示
```

## 接口

### 旧入口：整段精确卷积

```python
from exact_conv import convolve, plan_moduli

result = convolve(a, b)
result.coefficients     # list[int]：C[k] = sum_{i+j=k} a[i]*b[j]，精确整数
result.moduli           # tuple[int,...]：实际选用的 NTT 模数（最少个数）
result.coefficient_bound    # B = min(n,m) * max|A| * max|B|
result.modulus_product      # 所选模数乘积 M，保证 M > 2*B
result.transform_length     # 补零后的 NTT 长度（2 的幂）
```

- `a`、`b`：整数系数的可迭代对象（list/tuple/生成器均可），长度 1..256。
- 系数必须是 `int`，绝对值 `<= 10**6`。
- 返回长度 `len(a) + len(b) - 1` 的精确整数列表；输入不会被修改。

### 新入口：固定块长分块卷积 `convolve_blocked(a, b, block_size)`

```python
from exact_conv import convolve_blocked

result = convolve_blocked(a, b, block_size)
result.coefficients          # 与学校乘法一致的精确整数列表
result.block_size            # 实际使用的固定块长
result.blocks_a, result.blocks_b     # 两个输入各被切成的块数
result.block_pair_calls      # 调用旧精确卷积的块对次数 = blocks_a*blocks_b
result.transform_length      # 块对卷积使用的最大 NTT 长度（2 的幂）
result.moduli                # 各块对实际用到的模数并集（按优先顺序）
result.work                  # WorkArrayStats：工作数组大小统计
```

- 把两个输入（**长度不限**，最后一块可较短）从低次项起按同一个固定
  `block_size` 切块；每块长度 ≤ 256，因而每对块都能直接调用旧 `convolve`。
- 每对块的精确卷积按块起点偏移 `(i*block_size + j*block_size)` **重叠累加**
  进长度 `n+m-1` 的输出数组——即“分段相乘、错位相加”的学校乘法。负系数
  由旧卷积的 CRT 对称区间恢复直接支持。**零块也照常调用**旧卷积，不跳过、
  不特判，故块对调用数恒为块数之积。
- `block_size` 必须是精确正 `int`（拒绝 `bool`），范围 `1..256`。
- 系数约束与旧入口完全相同：`int`、绝对值 `<= 10**6`，拒绝
  `bool`/`float`/`NaN`/`Infinity`。长度限制解除后，旧入口的全部类型与
  系数界校验在新入口对任意长度依然生效。

`WorkArrayStats` 的单位是“整数槽位”（一个列表元素；不是字节数，Python
大整数实际字节占用随数值增长），字段：

| 字段 | 含义 |
|---|---|
| `accumulator_slots` | 重叠累加输出数组长度 `n+m-1`（全程存活） |
| `transform_length` | 任一块对的最大 NTT 长度（2 的幂） |
| `total_ntt_slots` | 所有块对 NTT 工作数组长度之和（累计申请，串行用后即释放） |
| `total_block_result_slots` | 所有块对精确卷积结果长度之和（重叠累加写入总槽位） |
| `max_residue_row_slots` | 最忙块对中各模数余数行槽位 `max len(moduli)*(块结果长)` |
| `peak_working_slots` | 同一时刻存活槽位的保守上界：累加数组 + 单次块卷积内同存数组（3 个 NTT 数组 + 余数行 + 块结果） |

`plan_moduli(n, m, max_abs_a, max_abs_b)` 是纯函数的模数规划，返回
`(moduli, bound, modulus_product)`，可在不做卷积时单独查询“最少要用几个模”。

### 固定常量

| 项 | 值 |
|---|---|
| NTT 素数（按优先使用顺序） | `1004535809`, `998244353`, `469762049` |
| 原根 | 均为 `3` |
| 最长变换支持 | 分别 2^21 / 2^23 / 2^26 点（本库最多用到 1024 点） |
| 单多项式长度上限 | `MAX_POLY_LENGTH = 256` |
| 系数绝对值上限 | `MAX_COEFF_ABS = 10**6` |

### 错误语义

所有本库错误继承 `exact_conv.ExactConvolutionError`（同时是 `ValueError`）：

- `InvalidPolynomialError`：不是系数可迭代对象（如整数、`None`、字符串）。
- `LengthOutOfBoundError`：空序列或长度超过 256。
- `InvalidCoefficientError`：系数不是精确 `int`——**拒绝 `bool`**
  （`True/False` 虽是 `int` 子类也拒绝）、拒绝 `float`，并对
  `NaN` / `Infinity` 给出明确可定位信息；拒绝字符串、`None`、复数等。
- `CoefficientBoundError`：系数绝对值超过 10^6。**直接拒绝而非取模冒充
  精确结果。**
- `UnprovableBoundError`：固定三模数乘积仍不足以保证 CRT 唯一恢复（在
  256×10^6 的单块接口上限内不会发生）。它表示“数学上无法证明精确”，与任何
  搜索预算耗尽之类的运行期失败明确区分。
- `InvalidBlockLengthError`：`convolve_blocked` 的 `block_size` 非法
  （不是精确 `int`——拒绝 `bool`/`float`，或不在 `1..256`）。

错误信息都带参数名与下标，例如 `a[2] ...`、`b[1] ...`，不静默纠正输入。
`convolve` 与 `convolve_blocked` 都是无状态纯函数：全部校验在任何计算或
输出数组分配之前完成，校验失败不产生累加数组、不改动输入、不留下半更新
状态。

## 算法与设计取舍

1. **校验先行**：任何计算前完成结构、类型、长度、系数界检查。
2. **按实际系数界选最少模数**。每个卷积系数是至多 `min(n,m)` 个
   `|a_i b_j| <= max|A|*max|B|` 之和，故
   `B = min(n,m) * max|A| * max|B|` 是可证上界。按固定顺序逐个加入模数，
   取第一个满足 **乘积严格大于 2B** 的前缀：
   - 单模覆盖约 `5e8`；
   - 双模（`1004535809*998244353 ≈ 1.003e18`）覆盖接口上限最坏界
     `256*1e12 = 2.56e14`，故接口内最多用两个模；第三个模
     `469762049` 固定保留并在 `plan_moduli` 中完整支持。
3. **迭代蝶形 NTT**（`exact_conv/ntt.py`）：补零到不短于 `n+m-1` 的最小
   2 的幂（接口内最多 1024 点）；原地 Cooley–Tukey 位反转蝶形，自行实现，
   不调用任何第三方同类算法。逆变换使用原根逆元并在末尾乘逆长度。
4. **Garner 混合基数 CRT**（`exact_conv/crt.py`）：增量合并各模余数，
   再把 `[0, M)` 代表折叠到对称整数区间 `(-M/2, M/2]`。由 `M > 2B` 且
   `|真值| <= B`，折叠结果与真值无歧义一致。
5. **朴素整数参考独立实现**（`tests/reference.py`）：只用双重循环按定义
   计算，**不导入被测核心**；测试期望值全部来自它。NTT 正逆往返、多模余数
   一致性等只作为补充检验。
6. **固定块长重叠累加**（`convolve_blocked`）：长度超过 256 的输入无法
   一次变换（块长受单多项式上限约束），故按固定块长切块后对*每一对块*
   复用步骤 1–5 的旧精确卷积，再把块卷积结果按
   `i*block_size + j*block_size` 偏移累加到统一输出数组。这与学校乘法
   “分段相乘、错位相加”恒等，因此不引入任何新的近似；各块对需要的模数
   仍按各自实际系数界独立选最少个数（零块界为 0，只需单模）。

## 误差口径

本库没有浮点结果：输入是整数，中间为模算术，输出为 Python 精确大整数。
**误差恒为 0，不使用任何容差**。所谓“对称区间恢复”是整数集合上的精确
双射（在 `M > 2B` 前提下），不是近似。

## 已知限制 / 非目标

- 旧 `convolve` 只实现本题契约的数学子集：三个固定素数、长度 ≤ 256、
  系数绝对值 ≤ 10^6；不宣称通用 NTT/CRT 行业标准兼容，不支持任意模数或
  任意原根配置。`convolve_blocked` 解除的只是*总长度*限制（按固定块长
  切块，单块仍 ≤ 256），系数界 10^6 与固定模数集合不变；块长本身也限定
  在 1..256。
- 纯 Python 实现，追求正确与可证性，而非 SIMD/原生级吞吐；接口规模下
  256×256 双模卷积为毫秒量级，300×300 分块（25 对块）演示实测约 25 ms。
  分块入口的块对数为 `ceil(n/bs)*ceil(m/bs)`，总长度越大调用越多，不做
  跨块的变换合并。
- 不提供网站、CLI 产品、报表等；终端命令仅用于跑测试与演示。
- 不保证输入序列惰性生成器可被重复消费（内部只迭代一次）。
- 工作数组统计只数整数槽位数组的*长度*与保守峰值上界，不计 Python 整数
  对象本身的字节占用，也不模拟分配器；本次迭代不含外存检查点、自选模数与
  严格总内存优化。
